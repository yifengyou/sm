# 第二部分 核心算法

本部分逐一剖析国密的六大算法。每个算法章节统一按"概述 → 数学/结构基础 → 算法流程（伪代码 + 数值示例） → 工作模式/派生用法 → 安全性分析 → 实现要点与互操作陷阱"组织。

先给一张总定位图：

```text
                     ┌────────────── 密钥协商 / 数字签名 / 公钥加密 ──────────────┐
                     │                        SM2（椭圆曲线，证书化 PKI）          │
                     │                        SM9（标识密码，免证书，KGC）         │
明文 ──► 杂凑 ◄──────┤                        （公钥层）                          │
         SM3         └──────────────────────────────────────────────────────────┘
           │
           │  完整性 / 摘要 / KDF / PRF
           ▼
       ┌────────── 对称加密 ──────────┐
       │  SM4（分组密码，块加密）       │  TLCP / VPN / 文件加密
       │  ZUC（序列密码，流加密）       │  4G/5G 空口保密性 128-EEA3
       │  SM1（不公开，硬件交付）       │  早期加密卡/加密机
       └─────────────────────────────┘
```

阅读顺序建议：SM3 最简单且是 SM2 的一部分，建议先读；随后 SM2、SM4；ZUC、SM9、SM1 可按需选读。
