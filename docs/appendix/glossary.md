# 附录 C：术语表

按主题分组。首次出现的章节约见括号标注。

## 体系与法规

| 术语 | 释义 |
| --- | --- |
| 国密 / 商密 | 中国商用密码体系的俗称；法定概念是《密码法》下的"商用密码"（第一部分） |
| 密码法 | 《中华人民共和国密码法》，2020-01-01 施行，密码法治的总纲（第一部分） |
| 商密条例 | 《商用密码管理条例》2023 修订版，密评/认证制度的细化（第一部分） |
| 密评 | 商用密码应用安全性评估，依据 GB/T 39786，结论分符合/基本符合/不符合（第四部分） |
| 测评单元 | 密评中可独立判定的最小要求单位，判定为符合/部分符合/不符合/不适用（密评章） |
| 方案评估 | 规划阶段对《密码应用方案》的前置评估，防"建成即不合规"（密评章） |
| 等保 | 网络安全等级保护；三级以上系统依法使用商密并接受密评（第四部分） |
| 关基 | 关键信息基础设施，每年至少一次密评（第四部分） |
| GM/T | 密码行业标准代号（"国密行标"） |
| GB/T | 推荐性国家标准代号 |
| 密标委 | 密码行业标准化技术委员会（标准发布与文本平台 gmbz.org.cn） |
| 商用密码产品认证 | 国密局与市场监管总局联合实施的密码产品强制认证目录制度（第一部分） |

## 算法

| 术语 | 释义 |
| --- | --- |
| SM1–SM9 | 商密算法序列编号（SM2/3/4/9 公开，SM1 不公开）（第二部分） |
| ZUC（祖冲之） | 国密序列密码，3GPP 128-EEA3/EIA3 内核（第二部分） |
| Z 值 | SM2 中绑定身份与曲线参数的预杂凑值 Z_A=SM3(ENTL‖ID‖a‖b‖Gx‖Gy‖x_A‖y_A)（SM2 章） |
| ENTL | SM2 用户标识的比特长度（2 字节），Z 值计算的前缀 |
| C1/C2/C3 | SM2 密文三分量：C1 椭圆曲线点、C2 密文、C3 摘要校验；新旧标准字段顺序不同（SM2 章） |
| C1C3C2 / C1C2C3 | 密文分量顺序的两个约定，互操作第一坑（SM2 章） |
| KAT | Known Answer Test，标准文本给出的已知答案测试向量 |
| ECDLP | 椭圆曲线离散对数问题，SM2 安全性的数学根基（SM2 章） |
| sm2p256v1 | GB/T 32918.5 规定的唯一推荐曲线（SM2 章） |
| 双线性对 | SM9 的数学引擎：e([a]P,[b]Q)=e(P,Q)^{ab} 的群映射（SM9 章） |
| BN 曲线 / 嵌入度 | SM9 所用配对友好曲线族；嵌入度 k=12 决定配对安全边界（SM9 章） |
| KGC | 密钥生成中心，IBC 体系中用主密钥派生用户私钥的可信机构（SM9 章） |
| IBC / 标识密码 | 公钥由用户标识直接派生的公钥体制（SM9 章） |
| hid | SM9 中区分用途的单字节识别符：签名 0x01、密钥交换 0x02、加密 0x03（GB/T 41389）（SM9 章） |
| exTNFS（Kim–Barbulescu） | 利用扩域结构加速 NFS 的算法（2016），将 256 位 BN 曲线实际强度下修至约 100~110 位（SM9 章） |
| EEA3 / EIA3 | 3GPP 基于 ZUC 的保密性/完整性算法（ZUC 章） |
| ZUC-256 | ZUC 的 256 位密钥扩展草案（ZUC 章） |
| GXM / MUR | GM/T 0001.4-2024 定义的 ZUC AEAD 模式（类 GCM / 抗误用）（ZUC 章） |
| HCTR | GB/T 17964-2021 新增的宽块可调加密模式（模式与 MAC 章） |
| CMAC / HMAC | 两组消息认证码构造；国密对应 CMAC-SM4 与 HMAC-SM3（模式与 MAC 章） |
| DRBG / TRNG | 确定性随机数发生器 / 真随机数发生器（随机数章） |
| 熵池 | 操作系统收集物理熵并缓慢播种随机源的机制（随机数章） |
| HNDL | "先截获后解密"：录制密文待算力成熟后回溯解密的攻击模型（后量子章） |
| Shor / Grover | 量子算法：前者击穿 ECDLP/分解，后者对穷举开平方（后量子章） |
| ML-KEM / ML-DSA / SLH-DSA | NIST 后量子标准（FIPS 203/204/205）（后量子章） |
| 密码敏捷性 | 系统在不重构的前提下替换密码算法的能力（后量子章） |

## 协议与证书

| 术语 | 释义 |
| --- | --- |
| TLCP | 传输层密码协议（GB/T 38636），国密版 TLS（TLCP 章） |
| 双证书 | 签名证书 + 加密证书的成对证书制度，TLCP 的核心设计（TLCP 章） |
| NTLS | TLCP 在 Tongsuo/BabaSSL 中的实现名（工程章） |
| RFC 8998 | TLS 1.3 使用 SM2/SM3/SM4 套件的规范（TLCP 章） |
| curveSM2 / sm2sig_sm3 | RFC 8998 注册的曲线组（=41）与签名方案（=0x0708）（TLCP 章） |
| 预主密钥 / master_secret / key_block | TLS 系密钥推导链条，TLCP 同构（TLCP 章） |
| PRF | 伪随机函数；TLCP 的 PRF 基于 HMAC-SM3（TLCP 章） |
| WAPI | 无线局域网鉴别与保密基础结构，SM4 的诞生地（VPN 章） |
| WAI / WPI / ASU | WAPI 的鉴别/保密子体系与鉴别服务器（VPN 章） |
| KMC（密管中心） | 托管加密私钥、支持恢复的密钥管理机构（证书章/密钥管理章） |
| CA / RA | 证书认证机构 / 注册机构（证书章） |
| CSR / CRL / OCSP | 证书请求 / 撤销列表 / 在线状态协议（证书章） |
| PKCS#8 / #12 | 私钥信息语法 / 私钥+证书容器（消息语法章） |
| 数字信封 | SM4 加密内容 + SM2 加密内容密钥的组合结构（消息语法章） |
| GB/T 35275 | CMS 的国密化消息语法标准（消息语法章） |
| OFD | 中国版式文档格式（GB/T 33190），电子发票/证照载体（应用章） |
| 电子签章 | GM/T 0031 / GB/T 38540 体系的印章数据结构与验证流程（应用章） |
| TSA / 可信时间戳 | 可信第三方对「数据摘要 + 时间」的签名背书（GM/T 0033），抗抵赖闭环要件（消息语法章） |
| TePA / 三元对等鉴别 | 客户端—鉴别服务器—接入点三方对等鉴别机制，WAPI 的鉴别基础（VPN 章） |

## 工程与硬件

| 术语 | 释义 |
| --- | --- |

| 密码卡 / 密码机 / 云密码机 | PCI-E 加密卡 / 独立服务器密码设备 / 云托管形态（工程章） |
| HSM | 硬件安全模块（Hardware Security Module）的通称 |
| SE | 安全芯片（Secure Element），嵌入式根信任载体 |
| UKey | USB 形态的智能密码钥匙 |
| 三层密钥架构 | 根密钥→密钥加密密钥→数据密钥的层级包裹结构（密钥管理章） |
| 信封加密 | 用 KEK 包裹 DEK 的数据加密组织方式（密钥管理章） |

| bitslicing | 把算法按位切片、用宽寄存器并行多实例的软件优化技术（SM4 章） |
| 侧信道 | 时序/功耗/缓存等物理信息泄露通道（SM2 章/SM9 章） |
| 无效曲线攻击 | 传入非法曲线点套取私钥信息的攻击，公钥校验是对策（SM2 章） |

| TCM / TPCM | 可信密码模块 / 主动度量的可信平台控制模块（可信计算章） |
| 度量链 / PCR | 逐级 SM3 扩展的平台完整性记录（可信计算章） |
| 封密存储 | 密钥解密与平台状态（PCR 值）绑定的机制（可信计算章） |
| ASN.1 / DER | 抽象语法记法与它的二进制编码，证书/密文封装的载体（证书章） |
| OID | 对象标识符；中国密码标准弧 1.2.156.10197（标准章） |
| 提供者（Provider） | OpenSSL 3.x 的算法供给架构，国密多栈共存的基础（工程章） |
