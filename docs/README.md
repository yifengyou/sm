# 国密技术知识手册

本手册系统梳理中国商用密码（俗称"国密"、"国密算法"、"SM 系列算法"）的技术体系，覆盖算法原理、协议设计、证书体系、工程实现、合规评估与专题深化六个维度。内容面向安全工程师、密码应用开发者和架构师，力求"知其然亦知其所以然"——不仅讲每个算法怎么用，更讲清楚它的数学结构、设计取舍、安全边界与工程上的坑。

## 内容结构

* **第一部分 总览**：国密是什么、从哪里来、算法族谱与发展时间线；标准体系（GB/T、GM/T）与法律法规（密码法、商用密码管理条例）。
* **第二部分 核心算法**：SM2（椭圆曲线公钥密码）、SM3（杂凑）、SM4（分组密码）、SM9（标识密码）、ZUC（序列密码）、SM1（受限算法）的完整技术剖析，含参数、轮函数、伪代码、标准测试向量与数值级示例。
* **第三部分 协议与应用**：TLCP 传输层密码协议（双证书握手全流程）、国密证书与 PKI/密管体系、软件库与硬件设备选型、性能优化与迁移策略。
* **第四部分 安全评估**：GB/T 39786 与商用密码应用安全性评估（"密评"）的框架、流程、常见不合格项与整改路径。
* **第五部分 专题深化**：随机数与随机性检测（GM/T 0005）、密钥管理（含协同签名）、消息语法与数字信封（GB/T 35275）、工作模式与 MAC 国标（GB/T 17964 / 15852.1）、VPN 协议族与 WAPI、可信计算与 TCM、行业应用画像、工控与 OT 国密化、电子合同与存证出证、密码服务平台与密码中台、后量子时代的国密。
* **附录**：国密标准总索引（速查表）、常见问题 FAQ、术语表。

## 术语约定

| 术语 | 含义 |
| --- | --- |
| 商用密码 / 商密 | 《密码法》框架下用于保护不属于国家秘密信息的密码技术，"国密算法"是其算法子集的俗称 |
| SM | "商密"（ShangMi）拼音首字母，后接序号，如 SM2、SM3、SM4、SM9 |
| GM/T | 密码行业标准代号；成熟后通常"升级"为国家标准 GB/T |
| TLCP | 传输层密码协议（GB/T 38636），国密版 TLS |
| 密评 | 商用密码应用安全性评估 |
| KAT | Known Answer Test，标准文本给出的已知答案测试向量 |

## 阅读建议

* 想快速建立全局认识：按顺序读第一部分，再浏览第二部分各章的"概述"节。
* 做国密改造 / HTTPS 双证书：直接读 SM2、TLCP、证书、工程实现四章。
* 做合规与密评：重点读标准法规、TLCP、密评三章，再用第五部分随机数/密钥管理两章自查。
* 做工控/OT 改造：TLCP 与 VPN 章打底，重点读工控章（协议路线抉择 + 电力样板）。
* 建电子合同/存证平台：消息语法章（信封与时间戳）打底，重点读电子合同章（法律框架 + 五环节技术栈）。
* 规划密码基础设施：密钥管理、密码模块章打底，重点读密码服务平台章（架构与论证边界）。
* 遇到具体报错或选型疑问：先查附录 B（FAQ），再跳转到对应章节。
* 查标准编号：附录 A（标准总索引）。

> 标准文本是唯一权威来源。本手册基于公开标准（GB/T、GM/T、ISO/IEC、RFC、3GPP）整理，撰写时已用参考实现复核文中算法流程与测试向量（SM3/SM4/ZUC 与官方 KAT 及独立实现双重复核；HMAC-SM3/HKDF-SM3 与 OpenSSL 独立实现交叉复核；CMAC-SM4 按 RFC 4493 同构构造自算；EEA3/EIA3 官方向量取自密标委英译本并程序复现；SM2 曲线参数与签名/加密/密钥交换/确定性签名示例程序验证全链路；SM9 密钥派生链及附录 A~D 全部非配对分量程序验证，**配对驱动分量（签名 h、KEM/加密的 K）另经 gmalg 独立实现交叉复核**；SM4-GCM/CCM 与 RFC 8998 向量逐字节验证；TLCP 套件编码与 OID 经 Tongsuo/OpenSSL/BouncyCastle 源码核对）；标准会修订，工程落地请以最新版官方文本与国家密码管理局公告为准。仓库附带两个复核脚本：`scripts/verify_test_vectors.py`（76 项，纯标准库零依赖）与 `scripts/verify_sm9_pairing.py`（11 项，SM9 配对分量，依赖 gmalg），读者可自行验证手册全部 KAT 与数值示例。
