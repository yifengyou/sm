# 国密标准体系与密码法规

国密的落地不是"拿来一个算法就能用"，而是一张由**算法标准 → 接口标准 → 协议标准 → 产品标准 → 检测认证 → 评估**织成的网。本章梳理这张网的全貌，是后续所有章节的"索引页"。

## 1. 标准分级

| 代号 | 含义 | 示例 |
| --- | --- | --- |
| **GM/T** | 密码行业标准（推荐性），国密体系的"第一落点" | GM/T 0004-2012（SM3） |
| **GB/T** | 推荐性国家标准，算法与协议成熟后的"升格目标" | GB/T 32905-2016（SM3） |
| **GB** | 强制性国家标准（密码领域极少使用） | — |
| 国际标准 | ISO/IEC、3GPP、IETF | ISO/IEC 10118-3、TS 35.221、RFC 8998 |

一条重要的经验规律：**同一个技术对象，GM/T 与 GB/T 的内容基本同源，GB/T 发布后应以 GB/T 为准**；但部分接口类、产品类标准长期只存在于 GM/T 层。

| GM/T 0015-2012 → **2023 修订版** | 数字证书格式 | 国密 X.509 证书与双证书体系的格式依据（2024-06-01 起旧版废止） |
| GM/T 0125.1~.4-2022 | JSON Web 密码应用语法规范 | JWS/JWE 的国密对应物——应用层 JSON 报文的签名/加密语法（国际侧 JOSE/COSE 尚无 SM 算法的正式 RFC 注册） |

### 2.3 接口标准（工程接线的"插座"）

| 标准 | 名称 | 面向设备 |
| --- | --- | --- |
| GM/T 0018-2012 → **2023 修订版** | 密码设备应用接口规范（**SDF**） | PCI-E 密码卡、服务器密码机等（C 语言函数族，`SDF_` 前缀） |
| GM/T 0016-2012 → **2023 修订版** | 智能密码钥匙密码应用接口规范（**SKF**） | USB-Key（`SKF_` 前缀函数族）；国标版 GB/T 35291-2017；配套 GM/T 0017-2023（数据格式）、GM/T 0027-2014（技术规范） |
| GM/T 0019-2012 → **2023 修订版** | 通用密码服务接口规范 | 密码中间件/密码服务平台（设备无关的上层接口） |
| GM/T 0127-2023 | 移动终端密码模块应用接口规范 | 手机 App 内的密码模块（协同签名/TEE 方案的接口层） |
| GM/T 0136-2024 | 密码应用 HTTP 接口规范 | 密码服务以 HTTP API 形态对外提供（密码中台/云密码服务） |

三个经典接口自下而上：**SKF/SDF 直连设备，0019 把设备差异抹平成统一密码服务**。合规系统中应用不应直接调用某块卡的私有 SDK，而应通过这三层之一；移动端与云服务场景则看 0127/0136。

## 3. 法律法规

### 3.1 《密码法》（2020 年 1 月 1 日施行）

关键条款对工程的影响：

- **第二十七条**：法律、行政法规和国家有关规定要求使用商用密码进行保护的关键信息基础设施，其运营者**应当使用商用密码进行保护**，并**自行或委托商用密码检测机构开展商用密码应用安全性评估**；自行检测评估的，应报送评估报告。这条是"密评"的直接法律依据。
- **第二十六条**：商用密码科研、进出口、检测认证制度；推行商用密码**检测认证**体系（与市场监管总局联合目录管理）。
- **分类管理**：核心密码/普通密码/商用密码三级体系（见总览章）。

一句话总结密码法对开发者的含义：**你的系统若被认定为关基或按等保三级以上要求保护，用不用商密、用得合不合规，就从"技术选型"变成了"法定义务"**。

### 3.2 《商用密码管理条例》（2023 年修订，2023 年 7 月 1 日施行）

与 1999 年版相比，2023 年修订版与密码法对齐，要点：

- 明确**商用密码检测认证**制度：列入目录的产品须认证后出厂/销售；
- 细化**密评**要求：关基等系统定期评估（关基运营者每年至少开展一次密评）；
- 鼓励商用密码产业与技术创新，明确标准化与检测机构管理；
- 进出口管制与促进并行。

配套的部门规章（商用密码检测机构、密评机构管理相关办法）由国家密码管理局另行发布，做合规项目时应同步核对最新版。

### 3.3 与等保、关基的关系

```text
网络安全等级保护（等保 2.0）  ──►  定级备案（一至五级）
        │
        ├─ 第三级及以上系统 ──►  依法应当使用商用密码保护
        │                            │
        │                            ▼
        │                    GB/T 39786-2021《信息系统密码应用基本要求》
        │                            │
        │                            ▼
        └─ 关键信息基础设施（关基）──►  商用密码应用安全性评估（密评，关基每年≥1 次）
```

密评不是孤立审计，它引用等保的定级结论，与等保测评在时间、对象上通常协同开展。

### 3.4 密码法之外的法律生态

密码法不是孤立的一部法。合规设计时，下面几部法律要**拼在一起读**：

| 法律/法规 | 施行 | 与密码工程的交点 |
| --- | --- | --- |
| 《网络安全法》 | 2017-06 | 网络安全总纲；等保制度的法律来源 |
| 《数据安全法》 | 2021-09 | 数据分类分级与安全保护义务——加密是核心措施之一 |
| 《个人信息保护法》 | 2021-11 | 第 51 条明确"加密、去标识化"为个人信息处理者应采取的安全技术措施 |
| 《关键信息基础设施安全保护条例》 | 2021-09 | 关基认定与保护义务的落地条例——密评（每年 ≥1 次）的适用面随之扩大 |
| 《电子签名法》（2005 施行，2015/2019 修正） | — | 可靠电子签名与手写签名/盖章具有同等效力；技术四要件映射见第四部分 |
| 《出口管制法》及配套公告 | 2020-12 | 部分商用密码物项纳入出口管制清单（见 3.5） |

一句话定位：**密码法管"用什么密码、怎么管"，数安法/个保法管"哪些数据必须保护"，关基条例管"谁必须每年密评"**。

持牌 CA 的"两证"也在此一提：工信部《电子认证服务许可证》+ 密码管理部门的电子认证服务密码使用许可（《电子认证服务密码管理办法》体系）——自建国密 CA 前先核对这个门槛。

### 3.5 商用密码进出口

- 依据《出口管制法》（2020-12-01 施行），商务部会同工信部、国家密码管理局、海关总署发布公告，将部分商用密码物项（如高性能密码设备与特定实现）纳入出口管制清单，**清单与许可程序动态调整，以商务部/国密局现行公告为准**；
- 对出海团队：出口前核对现行清单；对采购进口密码产品的团队：列入认证目录的商用密码产品**进口同样须取得认证**（与国产产品同规则）；
- 商密条例同时保留"促进"面：一般性商用密码技术交流与产品贸易不受无谓限制，管制聚焦高安全等级物项。

## 4. 商用密码产品认证

- 依据密码法及认证目录，**密码算法、密码模块、密码产品**（智能密码钥匙、密码卡、密码机、VPN 产品、安全芯片等）实行统一认证，发证机构为国家密码管理局与市场监管总局联合指定的认证机构。
- 合规选型的第一条铁律：**涉密评/关基项目中使用的密码产品，必须持有有效的商用密码产品认证证书**（可在国家密码管理局官网查询目录），"自研算法""魔改 SM4"都不在合规范围内。
- 密码模块按 **GB/T 37092-2018**（行标版 GM/T 0028，修改采用 ISO/IEC 19790）划分安全等级（1–4 级），等级越高对物理防护、侧信道防护、自测试要求越严；密评对不同等级系统对应不同的模块等级要求（等级体系与认证流程详见第五部分《密码模块与产品认证》一章）。

## 5. OID 体系：国密的"门牌号"

GM/T 0006 在国际 OID 树上注册了中国密码标准弧 **`1.2.156.10197`**（1.2 = ISO member body，156 = 中国，10197 = 密码标准）。工程中最常打交道的几个：

| OID | 含义 |
| --- | --- |
| 1.2.156.10197.1.301 | SM2 椭圆曲线（证书中作为 EC 曲线标识出现）；其下 301.1/.2/.3 分别为 SM2 签名/密钥交换/加密子算法 |
| 1.2.156.10197.1.401 | SM3 杂凑算法（401.2 为 HMAC-SM3） |
| 1.2.156.10197.1.501 | SM2WithSM3 签名算法（国密证书的 `SignatureAlgorithm`；502~50x 为 SM2 搭配 SHA 系列的变体） |
| 1.2.156.10197.1.104.x | SM4 工作模式族：.1 ECB、.2 CBC、.3 OFB、.4 CFB、.7 CTR、.8 GCM、.9 CCM、.10 XTS、.11 WRAP 等 |

实现差异提示：各库对 SM4 等算法的 OID 注册基本收敛到 GM/T 0006 的 104.x 模式族（OpenSSL、BouncyCastle 一致），但**跨库互操作时仍优先传"显式算法"而非依赖 OID 自动识别**。国密证书与协议相关的更多 OID 见第三部分证书一章。
