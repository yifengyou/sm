# 第三部分 协议与应用

算法只是原料，真正决定一个系统"国密改造"成败的是协议与工程。本部分覆盖三层：

1. **协议层**：TLCP（GB/T 38636）——国密版 TLS，双证书握手是其灵魂，也是国密 HTTPS 与 VPN 的核心协议；
2. **信任层**：国密数字证书与 PKI/密管体系——双证书从哪里来、OID 长什么样、CFCA 等根如何构成信任锚；
3. **工程层**：软件库选型（GmSSL/Tongsuo/BouncyCastle/gmsm…）、硬件与 SDF/SKF 接口、性能优化、双算法并存的迁移策略。

读完本部分，你应当能独立完成一个"国密 HTTPS 双证书站点"从证书申请、服务端部署到客户端联调的全流程，并知道每一步可能踩的坑。
