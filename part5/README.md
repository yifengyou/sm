# 第五部分 专题深化

前四部分走完了"总览 → 算法 → 协议 → 合规"的主线。本部分收拢那些**横跨多个系统层次、但在主线之外容易被忽略**的知识域——它们恰恰是工程实践和密评现场的高频考点：

1. **随机数与随机性检测**——密评不合格项第一名（随机数来源不合规）的根源，含 GM/T 0005 十五项检测与实测演示；
2. **密钥管理**——从三层密钥架构到 KMC 托管、协同签名（移动端"密钥不落盘"）；
3. **消息语法与数字信封**——GM/T 0010 / GB/T 35275 的 CMS 国密化，政务报文、电子文档的封装骨架；
4. **工作模式与 MAC 国标**——GB/T 17964-2021（含 HCTR 等中国特色模式）与 GB/T 15852.1 的八种 MAC 机制；
5. **安全接入协议族与 WAPI**——国密 IPSec/SSL VPN、以及 SM4 的诞生地 WAPI；
6. **可信计算与 TCM**——国密可信计算体系（TCM/TPCM）与等保"可信验证"；
7. **行业应用画像**——金融、政务、物联网/车联网、区块链等场景的典型国密栈；
8. **后量子与国密的未来**——量子威胁对 SM 算法族的差异化影响、PQC 标准化与混合迁移。
